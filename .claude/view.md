# 手机端设计通用原则

## 布局
- 移动优先：先设计手机版，再适配平板/桌面
- 舒适点击区：所有可点击元素 ≥ 44×44px
- 内容不过载：单屏 1~2 个核心动作
- 安全边距：左右至少 16px，内容不贴边

## 视觉
- 层级分明：标题/正文/辅助文字大小差距 ≥ 1.2 倍
- 留白呼吸：元素间距 ≥ 12px，区块间距 ≥ 24px
- 色彩克制：主色 ≤ 2 种，辅色 ≤ 3 种
- 对比度达标：文字与背景对比 ≥ 4.5:1（WCAG AA）

## 交互
- 即时反馈：点击有视觉/触觉反馈
- 加载状态：异步操作显示骨架屏或 spinner
- 手势友好：滑动返回、列表下拉刷新
- 键盘处理：输入时页面不上移遮挡

## 文字
- 字号舒适：正文 ≥ 15px，标题 ≥ 20px
- 行高合理：正文行高 1.5~1.6
- 一行足够：正文不超 15 字/行，移动端最佳
- 字体系统：中文用 PingFang SC / 苹方，英文用 SF Pro

## 其他
- 首屏速度：LCP ≤ 2.5s
- 暗黑模式：支持系统跟随或手动切换
- 断网容错：离线时有友好提示
- 简化动画：尊重系统弱网/低电量模式
